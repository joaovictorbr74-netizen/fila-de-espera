# 🍕 Grano Host

**Sistema de gestão de fila de espera desenvolvido para a Grano Pizza & Bar.**

O Grano Host foi criado para organizar o atendimento de clientes em momentos de alta demanda, oferecendo controle da fila em tempo real, comunicação via WhatsApp e uma experiência mais eficiente para a equipe da recepção.

---

## 📋 Sobre o Projeto

Em horários de pico, controlar uma fila de espera apenas com papel, anotações ou mensagens soltas pode gerar atrasos, erros e dificuldades para localizar clientes.

O Grano Host centraliza todo esse processo em uma única plataforma, permitindo:

* Cadastro rápido de clientes
* Controle da ordem de chegada
* Chamada via WhatsApp
* Atualização em tempo real entre dispositivos
* Registro de observações importantes
* Busca rápida por nome ou telefone

---

## 🚀 Funcionalidades

### 👤 Gestão de Clientes

* Cadastro de clientes na fila
* Nome obrigatório
* Telefone obrigatório
* Validação automática de telefone
* Máscara de telefone brasileira
* Impede números duplicados
* Edição de informações
* Observações personalizadas

### ⏳ Controle da Fila

* Ordem automática de chegada
* Tempo de espera atualizado em tempo real
* Status dos clientes:

  * Aguardando
  * Chamado
  * Acomodado

### 📱 Integração com WhatsApp

* Chamada do cliente com um clique
* Abertura automática do WhatsApp
* Mensagem personalizada
* Alteração automática de status após a chamada

### ☁️ Banco de Dados em Nuvem

* Integração com Supabase
* Persistência dos dados
* Sincronização em tempo real
* Atualização automática entre dispositivos

### 🔎 Busca Inteligente

* Pesquisa por nome
* Pesquisa por telefone
* Localização rápida de clientes

### 🔄 Segurança Operacional

* Remoção de clientes
* Opção de desfazer remoções
* Validação de campos obrigatórios
* Controle de integridade dos dados
